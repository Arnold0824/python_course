# CARLA 自动驾驶安全竞速模板

本项目是《自动驾驶软件系统B》期末大作业的个人基础代码模板。

教师提供的模板用于统一每位同学的起点，固定以下内容：

- 地图：`Town05`
- 背景车辆数量：`20`
- 行人数量：`30`
- 随机种子：`20260531`
- 同步模式和固定仿真步长
- 固定道路跟随路线和检查点
- 基础信号灯状态读取
- 基础碰撞事件和车道入侵事件记录
- 固定 60 秒计时、行驶距离、扣分统计和结果输出

同学们主要修改：

```text
src/student_policy.py
```

除非任课教师重新发布官方模板，否则不得修改以下公平性设置：

- 地图名称
- 路线生成规则
- 背景车辆数量
- 行人数量
- 随机种子
- 计时方式
- 评分规则
- 事件检测与扣分入口

## 运行前要求

1. 先启动 CARLA 服务端。
2. 确认当前 Python 环境可以导入 CARLA Python API。
3. 使用 Python 3.8 或以上版本运行。
4. 若要显示实时窗口，需要当前环境已安装 `pygame`。

如果运行时报 `import carla` 失败，需要设置 `CARLA_PYTHONAPI` 到本机 CARLA 的 PythonAPI 目录，例如：

```powershell
$env:CARLA_PYTHONAPI="D:\CARLA_0.9.15\PythonAPI\carla"
```

## 快速运行

在本项目目录下运行：

```powershell
python .\src\run_challenge.py --config .\config\default_config.json
```

脚本启动后会先弹出身份信息窗口，请输入学号和姓名。该信息会写入本次运行使用的配置、成绩报告和排行榜提交，不需要学生手工改 JSON。

模板默认开启在线排行榜提交。学生正常运行脚本并输入学号姓名后，程序会在结束时自动提交成绩：

```json
  "leaderboard": {
  "enabled": true,
  "submit_url": "https://niuniulab.com/api/carla/scores",
  "submit_token": "carla-final-2026-submit-token",
  "timeout_seconds": 5.0
}
```

当前 `submit_url` 已指向课程网站 `https://niuniulab.com/api/carla/scores`。如需关闭排行榜提交，把 `leaderboard.enabled` 改为 `false`；本地评分和结果文件不受影响。

如果只是先测试模板能否启动，可以减少仿真步数：

```powershell
python .\src\run_challenge.py --config .\config\default_config.json --max-ticks 600 --no-student-dialog
```

默认运行会打开一个 `pygame` 窗口。窗口开始时会先显示中文评分标准：计时窗口为 60 秒，沿固定路线向前推进的有效距离按 1 m = 1 分计分，最终成绩为 `max(0, 距离分 - 扣分合计)`。倒车或绕圈不会额外加分。按 `Enter` 或 `Space` 开始运行；按 `Esc` 或直接关闭窗口可以退出。

运行过程中，窗口摄像机会跟随主车，并在左上角显示中文 HUD 调试面板。按 `Esc`、`Q` 或直接关闭窗口，可以提前结束本次运行并写出结果文件。

运行结束后，如果 `pygame` 窗口仍然打开，界面会停在中文“成绩报告”页，显示学号姓名、计时窗口、行驶距离、距离分、最终成绩、扣分合计、扣分明细、固定设置校验和结果文件路径。该页面只会在按 `Esc` 或关闭窗口后退出，鼠标点击和普通按键不会关闭，学生可以直接截图放入实验报告。

运行结束后，脚本会根据配置尝试提交排行榜成绩。提交失败不会影响本地成绩文件生成；终端、`score_report.md` 和 pygame 成绩页都会显示提交状态。`config_used.json` 会自动隐藏提交令牌，避免把令牌写进结果包。

HUD 信息含义：

- `帧/时间`：CARLA 当前帧号和仿真时间，成绩以仿真时间为准。
- `速度/限速`：主车当前速度和当前道路限速。
- `行驶距离`、`当前距离分`：60 秒窗口内主车沿固定路线向前推进的有效距离和当前距离得分。
- `检查点`：已通过检查点数量/总检查点数量，判断是否真正推进。
- `路线进度`：检查点完成比例。
- `路线索引`：最近路线点和当前目标路线点索引，用于判断目标是否在前方连续推进。
- `路线偏移`：主车到路线的距离；持续过大说明偏航，需要降低速度或加强回正。
- `目标点索引`、`目标坐标`：当前 pure-pursuit 跟踪目标。
- `红绿灯`：当前交通灯状态；红灯时应停车，绿灯时应起步。
- `最近障碍`：前方动态障碍物距离；过近时应减速或停车。
- `最近碰撞`：最近一次碰撞类型和发生多久前；频繁出现说明策略太激进或脱困不足。
- `策略模式`：当前 `StudentPolicy` 判断，例如正常巡线、偏航回正、红灯停车、障碍停车、脱困倒车、脱困前进。
- `等待原因`：策略主动停车的原因，例如红灯或近距离障碍。
- `目标速度`：策略本 tick 想达到的速度，不等于当前实际速度。
- `航向误差`：车头方向和目标点方向的夹角；绝对值越大，越需要转向或降速。
- `控制`：本 tick 输出给 CARLA 的油门、刹车、转向和是否倒车。
- `累计扣分`、`事件数量`：当前已记录的扣分和事件数量。
- `输出目录`：本次运行结果文件所在位置。

如果只想后台运行，不显示窗口：

```powershell
python .\src\run_challenge.py --config .\config\default_config.json --no-render
```

后台运行仍会先询问学号和姓名。做自动化测试时可以加 `--no-student-dialog` 跳过身份弹框。

如果需要显示实时窗口但不想在开场评分标准页和结束成绩页等待操作，例如做自动化短测：

```powershell
python .\src\run_challenge.py --config .\config\default_config.json --max-ticks 600 --no-score-screen --no-student-dialog
```

结果会输出到：

```text
output/<运行时间戳>/
```

主要输出文件包括：

- `config_used.json`：本次运行使用的配置
- `trajectory.csv`：主车轨迹与状态日志
- `events.csv`：违规与安全事件日志
- `lap_summary.json`：距离挑战结果、扣分与最终成绩
- `score_report.md`：成绩报告

`lap_summary.json` 中的 `leaderboard_submission` 字段记录排行榜提交状态，例如成功、未启用、跳过或失败。

每次程序启动时，会打印固定地图、车辆/行人数量、随机种子、扣分规则和受保护配置校验摘要。现场答辩时，教师会根据这些信息快速检查是否使用了统一规则。

## 调试建议

先用短步数快速试运行：

```powershell
python .\src\run_challenge.py --config .\config\default_config.json --max-ticks 600 --no-student-dialog
```

常见现象和修改方向：

- 车速长期为 `0`，但红绿灯不是红灯、最近障碍也不是近距离：检查卡住检测和脱困参数。
- `策略模式` 频繁显示脱困倒车/脱困前进：转向、目标速度或路线偏移控制可能过激。
- `路线偏移` 持续大于 `12 m`：降低 `off_route_speed_kmh`，或改进回正转向。
- `航向误差` 经常超过 `45 deg` 且速度仍高：降低弯道速度或增强急弯降速。
- `最近碰撞` 频繁出现：降低目标速度、提前减速，或延长脱困倒车时间。
- `红绿灯` 为红灯但速度仍明显大于 `5 km/h`：提前停车，增大红灯停车距离或制动力。
- `累计扣分` 增长过快：打开 `events.csv`，按 `event_type` 查看主要扣分来源。

重点查看这些输出文件：

- `trajectory.csv`：逐 tick 抽样记录位置、速度、路线进度、红绿灯和障碍距离。
- `events.csv`：每次违规或碰撞事件，包含事件类型、扣分和发生位置。
- `lap_summary.json`：学号姓名、行驶距离、距离分、总扣分和最终成绩。

## 默认扣分规则

- 碰撞行人：每次扣 `15` 分
- 碰撞车辆：每次扣 `10` 分
- 碰撞静态物体：每次扣 `5` 分
- 闯红灯：每次扣 `5` 分
- 明显偏离路线：每次扣 `5` 分
- 车道入侵或压线：每次扣 `2` 分，最多扣 `10` 分
- 超速违规：每次扣 `3` 分，最多扣 `15` 分
- 长时间停滞：每次扣 `5` 分

## 学生任务

请在 `src/student_policy.py` 中改进主车的驾驶策略。

可以新增辅助模块，但现场演示必须仍然通过教师统一模板主程序运行：

```powershell
python .\src\run_challenge.py --config .\config\default_config.json
```

不得绕过或删除模板中的场景生成、事件检测、计时、扣分统计和成绩输出接口。

可以改进的方向包括：

- 直道和弯道的速度控制
- 红灯停车与绿灯起步逻辑
- 基于障碍物距离的减速或停车
- 更平滑的转向控制
- 路线进度跟踪与偏离路线恢复
- 更安全的车道保持
- 长时间停滞后的恢复策略
- 更安全但更高效的 Traffic Manager 参数策略

最终结果以 CARLA 仿真时间为准，不以电脑真实运行时间为准。

## 现场答辩说明

现场答辩时，学生需要在本人电脑上运行统一命令，展示程序启动、固定场景生成、固定路线行驶、事件监测、自动扣分和成绩输出过程。

若发现擅自修改固定地图、路线、车辆/行人数量、随机种子、计时方式、事件检测或扣分规则，相关运行结果按无效处理或酌情扣分。
